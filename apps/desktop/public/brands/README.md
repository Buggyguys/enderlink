# Upstream identity assets

These unmodified logos identify compatible third-party software/services; they are not Enderlink artwork or an endorsement.

- `paper.svg`: https://github.com/PaperMC/website/blob/main/src/assets/brand/paper.svg — PaperMC’s own website asset. Its MIT notice is included in `PaperMC-LICENSE.txt`.
- `fabric.png`: https://fabricmc.net/assets/logo.png — Fabric’s official site logo. Fabric name/logo remain with their owners.
- `playit.png`: https://github.com/playit-cloud/branding/blob/main/playit-logo-circle.png — Playit’s published branding repository. Playit name/logo remain with their owners.

Retrieved 2026-11-06. All Enderlink UI symbols in `src/components/Icons.tsx` and the app icon in `assets/enderlink-icon.svg` are original vector artwork in this project. No emoji or icon font is used for the interface.
